# Code of Conduct

RagKno is committed to a welcoming, respectful, and useful open-source community.

## Expected behavior

- Treat contributors and users with respect and patience.
- Give specific, constructive technical feedback.
- Respect differing experience levels, backgrounds, and viewpoints.
- Protect private information and report security concerns privately.
- Accept maintainers' decisions about scope, moderation, and project direction.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized content, deliberate disruption, publishing private information, and other conduct that makes participation unsafe are not accepted in project spaces.

## Enforcement

Report conduct concerns privately to the repository maintainers. Maintainers may edit or remove content, close discussions, reject contributions, or temporarily or permanently restrict participation when needed. Reports will be reviewed as privately and fairly as possible.

This policy applies to repository issues, pull requests, discussions, and other spaces where someone represents the RagKno project.
